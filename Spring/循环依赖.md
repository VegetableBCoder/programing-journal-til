# 单例Bean循环依赖时序分析

* Bean A 依赖Bean B 
* Bean B 依赖Bean A

## 时序分析

| A Bean操作 | B Bean操作 |
|---- | ---- |
| 调用getBean | | |
| 调用getSingleton传入factory(lambda)进行bean创建  | |
| 执行factory的getObject方法, 即执行createBean方法 |  |
| 调用doCreateBean进行实际操作 | |
| **实例化**| |
| **将实例化的对象包装成ObjectFactory扔到三级缓存**  ||
|**执行populateBean, 发现依赖B, 一二三级缓存都没找到B**| |
| | 被调用getBean |
| | 调用getSingleton传入factory(lambda)进行bean创建  | 
| | 执行factory的getObject方法, 即执行createBean方法 | 
| | 调用doCreateBean进行实际操作 | 
| | **实例化**| 
| | **将实例化的对象包装成ObjectFactory扔到三级缓存**  ||
| | **执行populateBean, 发现依赖A**| |
| **被调用getBean** |  |
| **三级缓存找到A的ObjectFactory**||
| **执行getObjects, 也就是执行getEealyBeanReference<br/>继承自SmartInstantiationAwareBeanPostProcessor<br/>的BeanPostProcessor在这一步就可以执行<br/>getEealyBeanReference方法<br/>spring会将AOP提前到这里就完成**||
| **将早期引用放入二级缓存, 清除三级缓存, 返回早期引用**| |
| | 将早期引用绑定到自己的属性上|
| | 执行initializeBean: PostProcessBeforeInitialize<br/>-initMethod-PostProcessAfterInitialize<br/>**代理在这里完成** |
| | 早期暴露检查, 避免其他bean引用这个bean的原始引用, 这里get直接返回的false, 跳过检查 |
| | ObjectFactory/createBean调用完成, 返回创建成功的Bean|
