# 磁盘存储

## 读写速度

* kafka采用顺序读写, 速度远大于随机读写

## 页缓存

* kafka作为基于JVM的应用, 没有自己实现文件数据缓存而是基于操作系统的页缓存
* 其他: 自己手动调节虚拟内存, 少使用在磁盘上的虚拟内存, 这会影响kafka性能

## 0拷贝

* 无0copy: disk ->(DMA) readbuffer ->(CPU) jvm ->(CPU) socket buffer ->(DMA) 网卡的nicbuffer
* 0copy: disk-> readbuffer-> 网卡
  * 无需将数据copy到jvm内存中(也就是无需从内核模式复制到用户模式), 应用只需要拿到一个描述符
  * 发送到网卡时也无需把readbuffer复制到socket buffer(), 只需要将描述符和长度信息加到socket buffer中, DMA直接从内存将数据复制到网卡缓冲区
