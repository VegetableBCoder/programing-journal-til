# 持久化

## RDB

* 定期通过子进程BGSAVE RDB dump文件

### 触发条件

* dirty计数器, 满足规则多长时间段有多少次写操作即触发导出规则


## AOF

* 命令执行完根据命令执行的函数是否是写命令判断是否将其写入AOF缓冲区
* 服务器在执行完一个事件循环的时候调用flush将其写入文件
* 写入文件又有几种操作系统文件系统缓冲区刷新配置
  * 立即刷新到文件
  * 最多间隔1s刷新一次到文件
  * 交给操作系统自己决定
* 随着命令越来越多, AOF文件越来越大, 需要瘦身, 也就是重写AOF文件
  * 执行rewriteaof期间, 先将这期间的命令缓存到缓冲区里面
  * 根据数据库里面的数据重新生成得到这些数据的命令
  * 将缓冲区的命令追加到文件末尾
