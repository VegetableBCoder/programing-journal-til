# 分布式锁的实现

* 项目里用的redisson分布式锁
* redisson锁主要分为两块, 一块是lua脚本的逻辑, 用来取锁, 一块是java代码的逻辑, 用来做一些高级特性的实现
  * 首先是lua脚本, 利用了redis lua脚本执行的原子性实现了锁的获取和重入, 如果没有锁则取锁成功. 根据clientId和线程id判断是不是自己的锁, 如果是, 则锁重入, 计数增加, 否则返回取锁失败
  * java代码实现了锁的等待, 订阅锁释放消息, 取锁超时, 自动续期等功能
    * 首次取锁失败时, 会检查是否已经超时, 如果超时则返回取锁失败
    * 如果没有超时, 则订阅锁释放的消息, 同时进行等待, 最多等待到锁剩下的ttl和自己还能等待的时间的较小值
    * 如果收到了锁释放的通知, 或者等待时间到了, 线程会被唤醒, 唤醒之后尝试获取锁
    * 用了信号量去控制一个节点只有一个线程去竞争锁, 尽量减少线程唤醒数
    * 锁获取成功之后如果没有指定过期时间, 会使用看门狗机制去定时续期;
      * 每次续期的时候锁还存在就创建延迟任务继续续期, 直到被主动释放为止
