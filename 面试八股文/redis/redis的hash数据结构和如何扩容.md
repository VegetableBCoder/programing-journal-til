# redis的hash结构和扩容

## redis hash

* 可以由压缩列表和字典两种方式存储
  * 根据key-value个数和所有key-value是否小于某个阈值决定的
* 扩容首先是压缩列表括成字典这种情况, 相当于新建一个字典结构
* 字典扩容
  * 新建一个大小为两倍的新字典, 根原来的组成一个数组 hash[0]和hash[1]
  * 用户对这个hash执行完一条命令之后花一点时间偷偷迁移一部分数据到新的字典
  * 每搬一条数据, rehashIndex+1
  * 新增的操作只发生在hash[1]后面, hash[0]上的数据只会减少不会增加
  * 运行一段时间之后hash[0]被搬空, 就可以用hash[1]替换hash[0]了
  * 查询, 删除操作会在两个hash上同时进行
