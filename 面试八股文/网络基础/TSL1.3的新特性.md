# TLS 1.3的优化

* 移除一些不安全的加密算法和摘要算法
  * 密钥交换废除静态RSA和DH, 因为容易被监听
  * 加密认证强制使用AEAD模式, 废除CBC模式
  * 摘要算法废除MD5和SHA-1
* ServerHello之后的消息都可以加密
  * 使用和ECH相同的构造方式构造密钥, 但是使用的数学方法有点不同
* 缩短握手过程
  * ClientHello直接携带密钥, Serverhello响应密钥, 减少密钥协商时间
* 0-RTT恢复
  * 建立连接后缓存连接的密钥和票据这些信息, 客户端重连时直接带上票据和数据, 服务端验证以后直接处理数据, 方便移动端在弱网环境下断网重连
